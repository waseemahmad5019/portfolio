About

A WordPress developer who treats page speed like a personal grudge.

I’m Waseem Ahmad, a WordPress developer and Technical SEO specialist based in Lahore, Pakistan. I build custom WordPress and WooCommerce websites and make them quick to load, easy for search engines to crawl and hard to break.

My work covers Core Web Vitals, Cloudflare, security hardening and malware cleanup, REST API integration and React.js frontends — plus the Ubuntu VPS, Nginx and PM2 setups they run on. I also build AI-powered SEO workflow automation for keyword and topic research.

My background includes web design on WordPress, Joomla, OpenCart and Magento at a Lahore software company, eight years of IT and digital operations support for the Health & Population Department, Government of the Punjab, and project-based WordPress and Technical SEO work ever since.
